How to group generation by category

Use the built-in selectors from PowerAnalytics.Selectors when you want Metric API results grouped by fuel or technology categories from deps/generator_mapping.yaml, instead of by component type alone.

Use the built-in categorized selector

using PowerAnalytics
using PowerAnalytics.Metrics
using PowerAnalytics.Selectors

# One column per category present in the results' system (PV, Wind, Coal, …)
calc_active_power(categorized_generators, results)

categorized_generators is a single ComponentSelector whose groups are the generator categories in the default mapping (storage and load categories are excluded). For injectors including storage and sources, use categorized_injectors.

To inspect the dictionary of per-category selectors:

generator_categories  # Dict{String, ComponentSelector}
keys(generator_categories)

Point at a custom mapping file

By default, the package loads deps/generator_mapping.yaml shipped with PowerAnalytics. To build selectors from your own YAML:

cats = parse_generator_categories("/path/to/generator_mapping.yaml")
sel = make_selector(values(cats)...)
calc_active_power(sel, results)

Use parse_injector_categories when you want every top-level category in the file, including those listed under __META.non_generators. See parse_generator_mapping_file for the full parse (selectors plus metadata).

YAML entries match on gentype (a PowerSystems.Component type name), primemover (PowerSystems.PrimeMovers), and fuel (PowerSystems.ThermalFuels). Category names should stay consistent with any downstream color palettes (for example PowerGraphics.load_palette).
